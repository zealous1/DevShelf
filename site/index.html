Connect DevShelf to your AI Coding Assistant

Official Model Context Protocol (MCP) Server • Zero-Paywall Tools & APIs

Ground Cursor, Claude Desktop, Windsurf, and Zed with 530+ verified zero-paywall tools, public APIs, and FOSS alternatives directly inside your AI coding chats:

File: .cursor/mcp.json (or Settings → Features → MCP) 
{
  "mcpServers": {
    "devshelf": {
      "command": "npx",
      "args": ["-y", "devshelf-mcp"]
    }
  }
}
File: claude_desktop_config.json

macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
Windows: %APPDATA%\Claude\claude_desktop_config.json 

{
  "mcpServers": {
    "devshelf": {
      "command": "npx",
      "args": ["-y", "devshelf-mcp"]
    }
  }
}
File: ~/.codeium/windsurf/mcp_config.json 
{
  "mcpServers": {
    "devshelf": {
      "command": "npx",
      "args": ["-y", "devshelf-mcp"]
    }
  }
}
File: ~/.config/zed/settings.json 
{
  "context_servers": {
    "devshelf": {
      "command": "npx",
      "args": ["-y", "devshelf-mcp"]
    }
  }
}

        💬 Frequently Asked Questions
      

      

        Answers for Developers & Search Engines
      

      

        Everything you need to know about DevShelf verification standards, zero-paywall policies, free alternatives, and machine integration.
      

    


    

      

        
          What is DevShelf and how are developer tools verified?
          ▼
        
        

          DevShelf is an open-source, community-curated directory indexing 540+ verified free developer tools, free public APIs, AI coding agents, and commercial software alternatives with zero paywalls. Every tool undergoes automated daily reachability checks, API health checks, and strict manual verification ensuring a permanent free tier or open-source license with no mandatory credit card or 14-day trial traps.
        

      


      

        
          What is the best free open-source alternative to Postman?
          ▼
        
        

          The leading free and open-source alternatives to Postman are Bruno (a fast, offline-first desktop API client that stores collections directly in your Git repository) and Hoppscotch (a lightweight, web-based open-source API request client). Both eliminate paid cloud account restrictions and team limits.
        

      


      

        
          Which free cloud databases and backends require no credit card?
          ▼
        
        

          Popular free cloud databases with no mandatory credit card include Supabase (generous free PostgreSQL database with Auth and Storage), Neon (serverless Postgres with instant branching), Turso (distributed SQLite powered by libSQL with a generous free tier), and PocketBase (an open-source single-file backend with real-time SQLite database).
        

      


      

        
          What are the best local LLM runners and AI coding tools?
          ▼
        
        

          Top free and open-source local LLM tools include Ollama (run Llama, Mistral, and DeepSeek locally with a simple CLI), vLLM (high-throughput inference engine), and DevShelf MCP Server (connects live catalog data directly into Cursor, Claude Desktop, and Windsurf).
        

      


      

        
          How do I connect AI coding assistants (Cursor, Claude Desktop, Windsurf, Zed) to DevShelf?
          ▼
        
        

          You can connect your AI coding agent directly to DevShelf via the Model Context Protocol (MCP) by running npx devshelf-mcp. Add it to your claude_desktop_config.json or Cursor settings under mcpServers to give your agent real-time access to 530+ free developer tools and alternatives.
        

      


      

        
          How does DevShelf detect trial bait and hidden paywalls?
          ▼
        
        

          DevShelf maintains automated trial bait analyzers and health probes that inspect pricing pages for deceptive 14-day trial expirations, mandatory upfront credit card gates, and silent sunsetting. Tools found violating zero-paywall criteria enter a 14-day grace period before being sunset from the catalog.
        

      


      

        
          How can developers submit an open-source tool or API?
          ▼
        
        

          Developers can submit tools via the interactive Contribution Wizard on the website or by opening a pull request on GitHub (github.com/RitualDev-Lab/DevShelf). All merged submissions receive social amplification across RitualDev Lab developer networks.
        

      


      

        
          Does DevShelf provide a public REST API and machine-readable data?
          ▼
        
        

          Yes. DevShelf exposes a zero-rate-limit public REST API at api/v1/tools.json, category feeds at api/v1/categories.json, live health stats at status.html, and LLM-friendly context at llms.txt.
