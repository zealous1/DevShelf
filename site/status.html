The 3 Distinct Verification Tiers

🌐 1. Reachable Web Endpoint

Probes DNS and HTTP connectivity (lastCheckedAt), distinguishing 200 OK, canonical 301 redirects, CDN bot-challenges, and genuine 404 dead links with a 14-day grace period.

🔌 2. Working API / Service Health

Validates live endpoint responsiveness (lastVerifiedAt). Tests that APIs and tools return valid, parseable JSON payloads matching declared OpenAPI or REST contracts.

The DevShelf Zero-Paywall & Sunset Protocol

1. Heuristic Trial-Bait Auditing

An automated auditor routinely parses landing pages, pricing grids, and terms of service. Mandatory upfront credit cards or discontinued free tiers trigger immediate review flags before users get trapped.

2. Real-World CDN Resilience

HTTP 403 / 429 challenge responses from Cloudflare, Vercel, or Akamai are treated as reachable origins with bot verification, avoiding false-positive deletions of legitimate community projects.

3. 14-Day Grace Period Sunset

Unreachable links undergo automated retries and enter a 14-day community grace period with public GitHub issue tracking. Only persistently dead resources (≥14 days or 3 consecutive failures) are sunset via automated PR.
